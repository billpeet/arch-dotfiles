# dotfiles

Arch + KDE Plasma 6 (Wayland).

## Layout

Each top-level directory is a package whose contents mirror `$HOME`
(GNU Stow layout):

| Package      | What                                                        |
|--------------|-------------------------------------------------------------|
| `bash`       | `.bashrc`, `.bash_profile`                                  |
| `git`        | `.gitconfig`                                                |
| `npm`        | `.npmrc` (global prefix only — no tokens)                   |
| `gh`         | GitHub CLI config (`hosts.yml` with auth is **not** tracked) |
| `ghostty`    | Ghostty config + systemd startup-race override              |
| `fontconfig` | `fonts.conf`                                                |
| `xdg`        | `mimeapps.list`, `user-dirs.dirs`                           |
| `kde`        | Plasma/KWin/theme/shortcuts/panel layout + KDE app configs  |
| `polycode`   | PolyCode AppImage launcher + icon (AppImage itself not tracked) |
| `elecwhat`   | ElecWhat launcher override using the official WhatsApp icon (copy of the packaged `.desktop`; re-sync if `elecwhat-bin` changes it) |

## Install

```sh
./install.sh            # link everything
./install.sh kde bash   # link specific packages
./install.sh -n         # dry run
./install.sh status     # check every managed file is still a symlink
```

Files are linked individually (not whole directories), so app state in
`~/.config` never ends up in the repo. Anything already in the way that
differs from the repo is backed up to `~/.dotfiles-backup/<timestamp>/`.

KConfig (all KDE apps) writes *through* symlinks, so changes made in System
Settings land straight in this repo — just `git diff` and commit. Some
non-KDE tools save by writing a temp file and renaming over it, which
replaces the symlink with a regular file; `./install.sh status` flags those
as `UNLINKED`.

## Adding a file

```sh
mkdir -p kde/.config
mv ~/.config/somerc kde/.config/
./install.sh kde
```

## Deliberately not tracked

- Secrets: `~/.ssh`, `~/.gnupg`, `gh/hosts.yml`, `opencode/service.json`
- Machine/hardware-specific: `kwinoutputconfig.json` (monitor layout)
- Runtime state: `kactivitymanagerd-*`, `kconf_updaterc`, `plasmanotifyrc`,
  `baloofilerc`, `session/`, `user-places.xbel`, `kdedefaults/`
- Generated by Plasma from `kdeglobals`: `gtk-3.0/`, `gtk-4.0/`,
  `.gtkrc-2.0`, `xsettingsd/` (re-apply the theme in System Settings to
  regenerate)
